# Steam Extractor 🕹️

**Extrator automático de avaliações (reviews) de jogos da Steam**, com filtro por idioma e período de data.

[![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/github/license/murillonunes/steam-extractor)](LICENSE)

## Funcionalidades

- 📥 Extrai **todas** as avaliações de um jogo via API da Steam
- 🌍 Filtra por idioma (`pt-br`, `en-us` etc.)
- 📅 Filtra por **intervalo de datas** (ex: 01/01/2021 à 31/12/2023)
- 💾 Salva em **JSON** estruturado para análise
- 🔄 Paginação automática via `cursor`
